# Projeto IBGE Analytics

Análise de dados públicos do IBGE usando Docker, PostgreSQL, FastAPI e Chart.js.

## O que este projeto faz

Extrai dados de população e mercado de trabalho por estado do IBGE
e exibe análises interativas em dashboard web.

## Tecnologias usadas

- Python + FastAPI (backend)
- PostgreSQL (banco de dados)
- Docker + docker-compose (containerização)
- HTML + Chart.js (frontend)
